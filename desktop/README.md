# lys-desktop

The packages the lys desktop's [shell](https://github.com/stubbedev/lys/tree/main/shell),
[login](https://github.com/stubbedev/lys/tree/main/login) and
[settings](https://github.com/stubbedev/lys/tree/main/settings) share: the config and its
schema, theming, translations, shared widgets and the clients of the desktop's
system services. It builds on [lys-ui](https://github.com/stubbedev/lys/tree/main/ui) and
[lys-lib](https://github.com/stubbedev/lys/tree/main/lib).

```sh
go get github.com/stubbedev/lys/desktop@latest
```
