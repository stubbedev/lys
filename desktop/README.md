# lys-desktop

The packages the [shell](../shell), [login](../login) and
[settings](../settings) apps of [lys](../README.md) share: the config and its
schema, theming, translations, shared widgets and the clients of the desktop's
system services. It builds on [lys-ui](../ui) and [lys-lib](../lib).

```sh
go get github.com/stubbedev/lys
```

The [manual](https://stubbedev.github.io/lys/desktop/) maps its packages.
