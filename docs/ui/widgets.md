# Widgets

Every component, captured from the current code on a headless sway at
scale 2 with its overlay open. The site's theme toggle switches the
palette.

The shots come from the gallery's `-shots` mode, run by
`just docshots ../docs/public/ui-widgets` in `ui/`, which writes them to
`docs/public/ui-widgets`. The site's build runs it before publishing.
